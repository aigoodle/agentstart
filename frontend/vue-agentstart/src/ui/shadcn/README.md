# shadcn-vue components

Source: https://shadcn-vue.com/r/styles/new-york/{name}.json (MIT).
These local sources belong to the library. Imports use relative paths because
`@` is reserved for legacy workflow modules. AgentStart adapters preserve the
existing public API; new UI uses these components directly. Theme tokens live
in `../shadcn.css`. Do not override colors per page or add a second UI library.
Icons use the renamed `@lucide/vue` package.
